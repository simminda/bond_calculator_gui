# Finance Calculator GUI

This is a simple GUI application that helps users calculate monthly loan repayments based on the loan amount, interest rate, and loan term.

## Features:
- Input fields for:
  - **Annual Interest Rate**
  - **Loan Term (in years)**
  - **Loan Amount**
- Calculates monthly repayments using the standard bond repayment formula.
- Easy-to-use interface with a background image to enhance user experience.

## How to Use:
1. Enter the **Annual Interest Rate** in the first input field.
2. Enter the **Loan Term** in years.
3. Enter the **Loan Amount**.
4. Click on the "Calculate" button to get the monthly repayment.
